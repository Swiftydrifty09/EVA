# JARVIS - AI Assistant

A holographic circular AI assistant inspired by JARVIS from Iron Man, featuring voice recognition, speech synthesis, and an immersive circular interface.

## Features

- **Circular Holographic Interface**: Authentic JARVIS-style circular design with multiple concentric rings
- **Voice Recognition**: Speak commands naturally
- **Text-to-Speech**: JARVIS responds with synthesized voice
- **Visual Effects**: Rotating interface, floating particles, and dynamic glow effects
- **Futuristic Design**: Dark space background with cyan holographic elements
- **Responsive Design**: Works on desktop and mobile devices

## Access Your JARVIS

**Your JARVIS is running at:** `http://localhost:8080`

Open this link in your web browser to access your holographic AI assistant.

## Interface Rings

The circular interface consists of multiple concentric rings:

1. **Outer Ring**: Input controls (text input and send button)
2. **Data Ring**: Response display area
3. **Interface Ring**: Voice activation button
4. **Status Ring**: System status indicator
5. **Core**: Central glowing core with pulsing effect

## Commands

Try saying or typing:
- "Hello JARVIS" - Greeting
- "What time is it?" - Current time
- "Tell me a joke" - Random joke
- "How are you?" - System status
- "Who are you?" - Introduction
- "Goodbye" - Farewell

## Visual Effects

- **Rotating Interface**: The entire circle slowly rotates
- **Grid Lines**: Holographic grid overlay
- **Floating Particles**: Animated particles around the interface
- **Speaking Effects**: Enhanced glow and particle effects when JARVIS speaks
- **Status Indicators**: Pulsing core and status lights

JARVIS uses your browser's built-in speech synthesis. For the best experience:
- Use Chrome or Edge for better voice quality
- Allow microphone access when prompted
- Try different browsers if the voice quality isn't satisfactory

## Technical Details

- Built with vanilla JavaScript
- Uses Web Speech API for voice recognition and synthesis
- Responsive CSS with futuristic styling
- No external dependencies required
